> 2023年もそろそろ終わり。今日は会社でも第4四半期の振り返りが終わったので、自分も年末のまとめを書いて、今年はいったい何をしてきたのか振り返ってみようと思う。

## 1. 仕事

**（自分について）**

まずは自分のことを少し紹介しておこう。江西省南昌にある二本大学（中国の大学入試で第二陣の募集区分に属する大学）を2022年に卒業して、今はバックエンド開発をしている。2021年9月から2022年3月までの6か月間は、杭州のHikvisionでインターンをしていた。2022年3月に小さな会社の秋採用で内定をもらい、卒業前からインターンとして働き始めた。2022年3月から2023年12月まで、あと3か月で丸2年になる。

**（生活リズム）**

今の会社は、あまりネット企業らしくないかもしれない。いわゆる965、朝9時から夕方6時まで、週5日勤務だ。会社の近くのマンションを借りていて、歩いて10分ほどで着く。毎朝9時に起きて9時半に出社し、昼休みは1時間半あるので家に帰って少し横になり、夕方6時に退勤する。バックエンドのリリースも夜には行わず、全部昼間にやっている。ユーザーが海外にいて時差があるからだ。周りの同級生や友人と比べると、ちょっと不思議な感じがする。みんなは日常的に残業しているのに、自分は1年以上働いて夜8時半まで残ったことが2回しかない。こんな会社はもうあまりないんだろうな、と思う。ただ、居心地のいい場所に長くいすぎるとダメになりそうで、ゆでガエルのような感覚もある。仕事が終わっても勉強する気にならず、ゲームや配信視聴、雀魂ばかりで、毎晩2時、3時まで起きている。

**（バックエンドの構成）**

会社のソフトウェア製品は主にアプリで、ユーザーも海外の人たちだ。バックエンド開発チームはリーダーを入れてたった4人。今年はバックエンドの技術構成も作り直した。主な構成は、JDK 17 + Spring Boot 3.0 + MyBatis-Plus + gRPC + WebClient + MySQL + Redis + Elasticsearch + Nacos（2.0）+ Apolloによるサービス登録・設定管理 + Mycatによるテーブル分割とコンシステントハッシュ + RocketMQ + Amazon SQSのメッセージキュー + log4j + slf4jによるログ記録／ELK + Flume + Logstashによる分散ログ保存 + Jiguang／FCMによるクライアントへのプッシュ通知 + Sensors Data（神策）の計測・イベント・A/Bテスト用SDK、といったところ。

業務がそれほど複雑ではなくユーザー数も多くないので、ミドルウェアを活用する場面はかなり少ない。RocketMQは主に商品のタイムセールの非同期処理や、外部サービスからのコールバックで大量のメッセージが発生する際の負荷平準化に使う。それ以外では、MQを実際に使う機会はあまりない。MQの活用例はたくさん読んだものの、自分の仕事にはその場面がない。Elasticsearchも主に検索やログ検索に使っていて、ワイドテーブルやデータ集計などに使うような場面はない。

**（仕事の中身）**

今年はずっと、ねじを締めるような単調な仕事をしていた。担当していたA製品は第1四半期の後に更新が止まり、B、C製品も第2四半期の開発を終えた後で止まった。どれも収益がよくなかったからだろう。D製品は少し利益が出ているので、第3、第4四半期もずっと開発を続けていた。個人向け製品ならユーザー数も多いはず、と思う人もいるかもしれない。でも自分が担当しているD製品を見てみると、1日のアクティブユーザーは2万〜3万人ほど。バックエンドでいう同時接続数やQPS、TPSがものすごく大きい場面には、今のところ触れられていない。

個人としては、担当する業務をしっかり理解することが大事だと思う。こちらの要件はそれほど複雑でも厄介でもなく、今の業務と新しい要件を理解して、開発のロジックを整理できれば、だいたい取りかかれる。高度な技術は必要なく、MySQLとRedisとSpring Bootがあれば進められる。最初のころは、アジャイル開発で要件を素早く実装していくことが成長につながっていた。CRUDにも不慣れだったところからすらすら扱えるようになり、確かに初級者の段階を抜ける助けにはなった。でも、その後も長く同じ操作、つまり情報を保存し、データを処理して情報を返すことを繰り返していると、あまり意味を感じられなくなってきた。質的に大きく伸びている感覚もない。

責任感という面では、最初は積極的にいろいろ引き受けていた。試用期間や入社したばかりのころは成長したいものだし、その気持ちはわかると思う。でも今は、できるだけほかの人に任せたい。残りの時間は自分のものにして、要件を実装し終えたら興味のあることをしたいと思っている。

最初は、コミュニケーションや自分の考えを伝える力にもかなり課題があった。プロダクトのレビュー会議や議論を重ねるなかで、少しずつ変わってきた。これから話すことを考え、筋道を整理して、焦らずゆっくり話すようにしている。

## 2. 技術の勉強

**言語について：** 仕事ではJavaとSpringのエコシステムを使っている。普段はPython 3でアルゴリズムを書いたり、Djangoで開発したり、クローラーやいろいろなスクリプトを書いたりしている。Goは興味のある分野としてアルゴリズムを書き、練習できそうなプロジェクトも探している。

**読書について：** 『Java仮想マシンを深く理解する（深入理解Java虚拟机）』『MySQLはどう動くのか（MySQL是怎么运行的）』『Redisの設計と実装（Redis设计与实现）』『Java並行プログラミング（Java并发编程）』『Go言語の設計と実装（Go语言设计与实现）』『Go言語による高並行処理とマイクロサービス実践（Go语言高并发与微服务实战）』『Javaマルチスレッドプログラミング（Java多线程编程）』『MySQL技術の内部（MySQL技术内幕）』『Pythonスクリプト（Python脚本）』『Linuxコマンドラインとシェルスクリプト（Linux命令行与Shell脚本）』........................

**技術的な解決策について：** 技術を動かすのは業務だと思う。大事なのは業務の場面に合わせて解決策を設計すること。場面があって初めて、複数の実装方法から技術を選べる。普段ある機能を見たら、どうやって実装しているのか、ほかにどんな方法があるのかを考えてみる。そうした解決策をまとめて、自分の知識体系を作っていきたい。

**オープンソースのミドルウェアについて：** まず何のためのものなのか、どう使うのかを理解し、全体のアーキテクチャを見る。自分はまだこの段階だ。その後でソースコードを読む。

とはいえ、自分の勉強も三日坊主。毎日だらだらしていて、基礎はまだしっかりしていない。

## 3. システムアーキテクト試験（45・36・49）

大学3年のとき、中国のコンピューター技術・ソフトウェア専門資格試験、いわゆる「軟考」の中級ソフトウェア設計者試験を受けて、無事に合格した。卒業した2022年には、実はもうシステムアーキテクト試験を受けたいと思っていた。高級職称があれば杭州のE類人材に認定され、杭州戸籍なら毎月2,000元以上の家賃補助を受けられるからだ。でも社会保険の加入月数が少なすぎて杭州の受験資格を満たせず、そのときはひっそり諦めた。システムアーキテクト試験は年に1回しか受けられない。今年は9月に申し込み、国慶節の休みになってからようやく教材を買って勉強を始めた。1か月準備して、浙江工業大学でコンピューター試験を受けた。今年は結果が出るのが早かったけれど、残念ながら不合格だった。事例分析の第1問は今年から出題形式が変わってビッグデータの問題になり、その範囲は勉強していなかったので、ほぼ0点だったと思う。その後のRedisやORMフレームワーク、MySQLのマスター・スレーブレプリケーションの問題もうまく答えられなかった。本当に惜しくて、ビッグデータの範囲を見ておかなかったことをかなり後悔している。論文については普段から書く練習をしておらず、試験前にテンプレートの構成を暗記した程度だった。本番ではシステムの安定性を選び、会社のプロジェクトを題材にして論文にまとめた。1か月準備したのに受からなかったことは、今年かなり後悔していることの一つ。来年また受けるかどうかは、まだわからない。

## 4. 暮らし

毎日きちんと退勤できるので、自分の時間はたくさんある。勉強していなければ、筋トレかサイクリングをしている................ 夏の間は、主に住んでいるマンションの敷地でバスケットボールをしていた。今年の独身の日、11月11日のセールではXDSのロードバイクを買った。杭州の有名な観光スポットを全部自転車で回ってみたいと思っている。今のところ主に行ったのは、西湖、湘湖、銭塘江、浙江大学の紫金・玉泉キャンパス。最近の杭州は寒すぎるので、ほかの場所の開拓はまた今度。

今年は趣味の幅を広げようと、ヤマハのギターも買って練習した。数か月ほど基礎を勉強したところで、放り出してしまったけれど。

その後、写真やカメラの動画をたくさん見るようになって、自分でもやってみたくなり、キヤノンのRPを買った。週末に時間があれば出かけて風景を撮っている。週末に外へ出て何かするほうが、借りている部屋にこもっているより充実している。2022年と比べると、今年はいろいろ違うことを始められた。残念なのはダイエットが失敗したこと。自分を律するのがどうにも苦手だ。
