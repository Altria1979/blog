# 验收规则

本文件区分 **Skill 交付验收** 与 **后续博客实现验收**。创建本 Skill 不代表博客已经实现或还原以下功能。当前参考版本与范围见 [SKILL.md](../SKILL.md)；规格、功能和数据事实分别见 [视觉规范](design-spec.md)、[功能矩阵](feature-map.md)、[内容迁移](content-migration.md)。

> 请使用本项目的 `$shinya-next-blog`，检查当前博客与 https://blog.shinya.click/、https://github.com/senshinya/blog 的差异，并提出下一轮修改安排。只读检查，不修改文件或访问需登录的服务。依据 Skill 中记录的用户约定处理范围。

## 后续实现：建立可比较的视觉证据

### 基线条件

| 场景 | 视口（CSS px） | 主要检查 |
| --- | --- | --- |
| 桌面 | 1440 × 900 | 三栏、精选、卡片、widgets、页脚；阅读头图和侧栏目录 |
| 平板 | 1024 × 768 | 右侧抽屉、左栏比例、菜单与分页避让 |
| 手机 | 390 × 844 | 左右抽屉、浮动开关、顶部封面、TOC 可达、无页面横向溢出 |
| 临界点 | 宽 1081/1080/1079、769/768/767、529/528/527；高 900 | 布局断点与窄卡切换；528px 还需单独测试卡片容器宽度 |
| 窄屏补充 | 320 × 740 | 字体、长标题、浮动开关与分页不重叠 |

对参考和本地使用相同 viewport、DPR、主题、缩放、滚动位置和组件状态，等待 `document.fonts.ready` 及封面完成加载。不同字体有不同实际覆盖，记录计算后的 font-family 和真实加载字体，不仅检查 CSS 声明。至少固定 DPR=1 的基线，字体问题再补 DPR=2。每张图记录时间、参考版本、页面、浏览器版本、主题、语言、视口、DPR、滚动位置、hover/focus/展开状态、字体及网络失败情况。

截图保存到本次任务的持久证据目录，并把绝对路径写入验收报告；不覆盖过去已审计的基线。用户提供的 [原始首页截图](reference-home-desktop.png) 像素尺寸为 2932 × 1522，实际 viewport/DPR、采集时间与字体状态未提供。图中的系统剪贴板浮层和底部浏览器状态条排除；它支持结构观察，不支持推导未知 CSS 像素。

品牌、文本、原创封面、暂缓模块属于有意差异，报告单列；字体角色、版式比例、遮罩、间距和行为仍需核对。使用近似长度的内容评估折行，不能用风景照片与插画差异替代布局判断。首页移除碎语后右栏顺序为统计→实际技术信息，不填入额外关于/分类/标签 widgets。

### 必须覆盖的视觉状态

- 首页默认、精选 hover 与键盘 focus、分类菜单开闭、第一页/第二页、分页收拢/展开；精选只在未筛选第一页显示。
- 浅色和深色；系统外观变化；语言胶囊打开、活动背景、禁用译文按钮；触摸与 reduced-motion。
- 阅读有图/无图头部、tech/story、长目录当前位置、移动目录抽屉、代码折叠/展开、灯箱与题注。
- 归档预览与密度切换、游记章节与地图；有证据的规格按 references 对照，尚未量测的部分先采样。

每轮有视觉修改时先比较截图，再决定下一处修正。把每一项标为 **通过／差距／待验证／暂缓／有意个人化**；总分不能盖过关键差距。

## 后续实现：功能场景

| 模块 | 验证行为与边界 |
| --- | --- |
| 首页 | 10 篇/页、排序与精选权重、循环拖动/触摸/滚轮/Shift+滚轮；分类选择关闭并重置页码；精选随筛选/分页隐藏；前进/后退恢复状态；无结果与无效页码有明确行为。 |
| 导航/抽屉 | 桌面 sticky 边界；平板右抽屉和手机左右抽屉可达；遮罩/Esc 关闭与焦点恢复；焦点不进入隐藏面板；搜索、分页与浮动按钮不遮挡。 |
| 搜索 | 用仅出现在正文中的词命中对应章节；代码区正文不入索引；实际索引字段、标题加权、前缀/模糊匹配及多词 AND；祖先标题参与检索/加权目前待验证，若修正须独立用例；中文/英文/日文分词、100ms 防抖、匹配高亮、面包屑和锚点；选中文本开搜、上下/Enter/Esc、空态与加载失败。 |
| 阅读/目录 | 目录层级/标题唯一 ID、重复标题与深链接；滚动激活当前与父章节、目录自动滚动；移动 TOC 可达；正文结束进度完成，页脚不计入；无图头部与无目录文章仍可读。 |
| 代码 | 32 行不触发“超过32行”折叠，33 行折为16行；复制原始文本、wrap/横滚、行号/diff/highlight/文件名；高亮加载失败仍显示转义纯文本，切主题可读。 |
| 图片 | 宽高占位/加载稳定、懒加载；打开被点击的图片、题注、关闭与焦点返回；未知尺寸和加载失败可读；不要按未经支持的图集上一张/下一张验收。 |
| 文章关系/分享 | 显式系列与普通邻接文章分别正确；首页与详情顺序一致；组合分享文案使用自己的正式 URL；参考资料、许可与作者声明按元数据呈现。 |
| 归档 | 年份与分类筛选、数量/字数、预览与密度；未配置生日不显示年龄。 |
| 三语/主题 | URL 是语言权威；只切到真实存在的对应译文，缺译文禁用且键盘不能激活；文章未翻译不制造同文三语路由；canonical/hreflang/页面 lang 正确；主题持久化、首次 hydration 与 system 变化一致。 |
| 游记 | 独立章节/照片/地图联动；同一 day 的多小节不被覆盖；无坐标照片、键盘/滚轮/触摸、手机地图折叠；无内容时诚实空态；WebGL/底图网络不可用时文字与照片继续可读。 |
| 公开内容 | 生产草稿、预览目录和草稿游记不进入页面/预渲染、搜索索引、客户端数据包、Feed、sitemap 或统计；开发预览与发布行为分别验证，不能只检查列表隐藏。 |
| Feed/SEO/统计 | `/rss.xml` 与既有文章 URL 可访问；真实译文 Atom/SEO；XML 与 JSON-LD 转义有效；统计同一文章不按译文重复累加；“最近更新”来自真实构建时间；域名、技术信息、图片存储来自当前配置。 |
| 错误与首帧 | 不存在文章/无效分页真实 404；直接打开和站内导航均正确；生产端 hydration 无错误，包括 404 侧栏；外部图片/地图失败不破坏正文。 |

友链按用户要求移除，不验收参考站的友链功能；只检查入口、配置、专用样式及 sitemap 条目已清除，`/links` 返回 404。评论、碎语、娱乐收藏不进入当前通过清单；只检查没有相关入口、作者服务请求或虚构数据。未来用户明确启用时再增加服务与对应验收。

## 运行检查与报告

需要实现代码的任务，运行当前项目提供的 `npm run lint`、`npm run typecheck`、`npm test`、`npm run build`。构建与类型检查可能共用 `.next` 生成物，应顺序运行相关步骤。先用 `package.json` 确认脚本；只读研究和纯文档变更无需伪造这些检查为“页面已还原”的证明。

浏览器验收前确认 URL 响应的是本项目，不能由端口号猜测。2026-09-30 独立只读测试中，3000 端口响应其他应用，未获得本博客运行截图；后续确认已有博客服务或为本项目选择空闲端口，不终止其他应用来占用端口。

修复解析器或内容模型时保留安全 URL、HTML 转义、标题 ID、草稿和日期现有回归用例，并补能证明新行为的用例。不要写仅复刻样式常数的测试。

报告列出改动文件、简化/复用、命令结果、截图和交互证据；视觉与功能各自写结论，记录余下差距、未验证点与外部资源限制。只有当前任务范围内的要求都有相应证据才宣称该模块完成。
