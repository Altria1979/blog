# 动画清单维护

三语入口为 `/anime`、`/en/anime`、`/ja/anime`。页面公开展示作者的记录，访客只能浏览与筛选。动画不进入文章搜索、归档、RSS 或文章字数统计。

## 填写已看作品

在 `content/anime/catalog.json` 查找作品及其 `id`，将 ID 填入 `content/anime/watched.json`：

```json
{
  "watchedIds": ["anime-2026-011"],
  "recordedDates": {
    "anime-2026-011": "2026-10-11"
  }
}
```

上面是《JOJO的奇妙冒险 飙马野郎》的当前记录，已按作者确认标记。`recordedDates` 表示添加这条已看标记的日期，精确到天，按上海日期维护；页面显示「记录于」，不是推测实际观看或看完的日期。三语共享相同日期，展示格式随语言变化。

日期可省略：只写 `watchedIds` 的旧记录仍然可用，不自动补今天或构建日期。填写日期时必须使用有效的 `YYYY-MM-DD`，且只能为已看列表中的作品添加。取消已看时一并移除对应日期。

初始的 `null` 表示尚未填写，页面显示「观影记录待补充」；`[]` 表示已填写且没有已看作品，统计才显示 0。三语共用同一组 ID，切换语言不会改变观看状态。

统计只计算当前年份范围内的作品。重复或不存在的 ID 会使校验失败，请修正后发布。页面没有在线编辑、访客本地观看记录或账户同步。

## 添加作品

每条作品包含以下字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一、固定的 ASCII 标识，例如 `anime-2026-001`。按该年份现有编号继续分配；调整标题或排序时不要重新编号。 |
| `year` | 此季动画首次开播、电影首次正式发行或剧场单元首次公映的年份，跨年续播、地区引进或重映不再重复添加。 |
| `titles.zh/en/ja` | 中文常用名称、官方英文名（没有时使用常见罗马字名）、日文名称。续作写清季数或篇章，三项均必填。 |
| `format` | 可选：`movie` 表示动画电影（含正式网络发行的电影），`theatrical` 表示分幕等剧场上映作品。仅核实后填写；旧条目不自动推断类型。 |
| `sourceUrl` | 补充作品的 HTTPS 核查来源，可用官方动画网站、播出平台或 Bangumi 条目。 |

片单收录日本 TV、网络动画、动画电影及剧场上映作品。基础数据来自 anime-sedai，增补作品依据公开收藏量等参考信息和官方发行资料人工筛选；这些参考不构成统一的全球人气排名。本轮电影扩充针对 2026 年，往年电影仍不完整。

电影和同系列电视动画使用独立 ID；仅把已核实正式发行的作品加入公开目录。纯总集篇、旧作重映、电视片段的影院先行场，以及尚未发行或发行日期未核实的作品不在新增范围中。电影先正式网络上线、后进入影院时只保留一个条目；同一内容先分幕剧场上映、后改为电视播放时，按已收录的各幕计数，不再增加电视版总条目。全新重制电影区别于原作重映，可以作为独立作品。

年份按从新到旧展示，同年保留文件中的顺序。默认展开最新年份并预览前 12 部，其他年份收起；「展开其余」可查看该年完整片单，收起后返回年份标题。12 部只是初始预览数量，不限制目录收录和统计。新增内容时检查同名别译、续作和分割季度，避免同一条目重复录入。不要因一部作品跨年续播而修改稳定 ID。

## 浏览、筛选与语言

`?range=5`、`?range=10`、`?range=15` 选择片单中最后 5、10、15 个年份；无参数或无效值显示全部。以片单年份计算，不随浏览当天的年份自动删除旧数据。语言切换、刷新及浏览器前进后退保留 URL 中的筛选值。

搜索使用 `?q=片名`，匹配全部年份的中文、英文和日文片名；忽略大小写与全／半角差异，多词查询要求每个词均命中。搜索期间保留但暂不应用 `range`，清空查询即恢复原年份范围。查询最长 120 个字符。

`?status=watched` 仅显示作者已标记的作品，可与查询和年份范围组合使用。没有观看记录时显示本地化空状态，不推断其他条目为「未看」。搜索或已看筛选时，所有匹配年份自动展开，并直接显示该年全部匹配作品，不受 12 部预览数量限制；仍可以逐年收起。

查询和筛选随 URL 保留，刷新、浏览器前进／后退和语言切换可恢复。年份展开状态用于当前浏览过程，不保存为个人偏好；有效的 `#anime-year-YYYY` 深链接会展开并定位到筛选结果中对应的年份。

点击作品卡可查看轻量资料弹层：完整三语片名、发行年份、已看状态、已填写的记录日期和可选的核查来源。来源链接不是统一的作品详情服务，未配置来源时不显示链接。桌面为居中弹层，手机为底部面板，支持关闭按钮、遮罩及 Esc，关闭后焦点返回原卡片。页面仍是作者清单，点击卡片不会修改观看记录。

数量、界面及作品名随语言变化，年份与已看状态保持一致。页面 canonical 指向无筛选参数的当前语言入口。

## 更新来源与发布

- 上游来源、固定提交和改编范围记录在 README 与 THIRD_PARTY_NOTICES，更新上游版本时同步维护并保留 MIT 声明。
- 每次补充记录作品名、年份、核查日期及来源，历年与 2026 的首次核查分别见 [历年补充记录](anime-catalog-audit.md) 和 [2026 年来源记录](anime-2026-research.md)。未来年份可增加对应来源记录。
- 2026 年以 2026-10-11 为本次核查截止日。之后开播、上映或信息不充分的作品只记录为候选，核实正式发行后再加入公开目录；电影公映日期采用日本首映口径，后续地区引进不改变年份。
- 不自动抓取网站，不引入封面、简介正文或实时评分；修改数据后运行 `npm run lint`、`npm run typecheck`、`npm test`、`npm run build`，并抽查三语页面。
- 数据随代码发布，更新后需重新构建部署。截图、测试中的示例观看状态不可写入正式 `watched.json`。
